## What comes from Offscreen

The scheduler and original tests, timing and monotonic clock foundations, activity/sleep handling, JSON preferences, login-item management, native window/menu infrastructure, and theme foundation were retained or adapted.

## What changed

Molaway adds independent eye/movement timers, automatic activity accounting, video signal handling, watching/presentation modes, optional meeting suppression, four reminder styles, display selection, English/Turkish localization, sound/theme controls, permission explanations, validated settings transfer, sandbox restrictions, overdue indicators, and optional local daily charts. The icon is original two-ring artwork created for Molaway.

The previous database dependency, app-content/screen-share/audio monitoring, global shortcuts, and upstream distribution scripts were removed. There are no third-party Swift package dependencies.
